배포 파일: 한빛정밀_생산품질실적_2026-07_10.xlsx / 품질혁신TF_성과보고서_2026하반기_초안.docx / 한빛정밀_보고서작성기준_Rev3.docx

## 14:00~14:30 인트로 (30분)
- 보고서 업무 시간 구조: 자료 취합 40% · 작성 35% · 검수 25% → AI가 줄이는 구간
- AI가 못 하는 것: 사실 확인 책임, 숫자 원천 검증, 조직 맥락 판단
- 오늘 흐름: 하나의 성과보고서를 프로젝트 → 스킬 → 에이전트 순으로 고도화

## 14:30~15:30 ① 프로젝트로 초안 작성·오탈자·일관성 검수 (60분)
1. 프로젝트 생성 "품질경영팀 보고서" → 지침 입력, 작성기준 Rev3 업로드
   - 지침: 「너는 한빛정밀 품질경영팀 보고서 검토자다. 업로드된 작성기준을 반드시 따른다. 수치는 근거 파일에 있는 것만 쓴다.」
2. 초안 업로드 후 프롬프트
   - 「작성기준 위반 항목을 표(위치/원문/위반기준/수정안)로 정리해줘」
   - 「보고서 안의 숫자끼리 서로 맞지 않는 곳을 찾아줘. 계산 과정도 보여줘」
   - 「경영진용 3줄 요약을 맨 앞에 추가해줘」
3. 토의: AI가 찾은 것 vs 놓친 것 (정답 대조는 강사 별도 메모)

## 15:30~15:40 휴식

## 15:40~16:40 ② 스킬: 데이터 분석 → 차트 → 보고서 반영 (60분)
1. 실적 엑셀 업로드 → 「데이터 품질 문제(중복, 빈칸, 표기 불일치, 이상치)를 먼저 찾아 보고해줘」
2. 「정제 후 월별·라인별 불량률, 불량유형 파레토 차트를 만들어줘」
3. 초안 4장 수치와 실제 데이터 비교 → 보고서 수정
4. 위 과정을 스킬로 저장: 「방금 한 절차를 '월간 품질실적 분석' 스킬로 만들어줘 (입력: 실적 엑셀 / 출력: 정제 내역, 지표표, 차트 2종, 보고서 문단)」
5. 다음 달 데이터라고 가정하고 스킬 재실행

## 16:40~16:50 휴식

## 16:50~18:00 ③ 에이전트: PC앱 + Cowork (70분 + Q&A)
1. Claude 데스크톱 앱 설치·로그인, Cowork 폴더 지정 (사전 공지: 유료 계정·설치 권한)
2. 폴더에 3개 파일 넣고 지시: 「폴더 자료로 성과보고서 최종본(docx)과 경영진 보고용 5장 슬라이드(pptx)를 만들어줘. 작성기준 Rev3 준수, 차트 포함」
3. 결과 검수 체크리스트: 수치 원천 / 용어 / 익명 처리(외부 제출본) / 예산 합계
4. 내 업무 적용 설계: 각자 반복 보고서 1개 선정 → 프로젝트·스킬·에이전트 중 무엇을 쓸지 작성
5. Q&A

### ③-추가: 피클(Pickle) — 보고서 이후의 '실행' 위임 (20분, Cowork 실습 뒤)
보고서를 만든 다음 실제로 손이 가는 후속 업무를 AI 비서에게 말로 맡기기
1. 보고 일정 잡기: 「다음 주 생산본부장님 일정 비는 시간에 성과보고 30분 잡고, 참석자(생산1·2팀장, 설비보전팀장)에게 초대 보내줘」
2. 자료 회람: 「최종 보고서 파일 TF 참여자 11명에게 메일로 보내고, 수정 의견은 금요일까지 회신해 달라고 써줘」
3. 미해결 건 추적: 「한결기공 클레임 조치 완료일 확인 전화(또는 메일) 해줘, 결과 메모로 남겨줘」
4. 리마인드: 「11/28 오전 9시에 예산안(8,000만원) 결재 올렸는지 알려줘」
- 정리: Cowork(파일·문서 만들기) + 피클(연락·일정·확인) = 보고 업무 처음부터 끝까지
- 재직자 체크: 회사 메일/캘린더 연동 가능 여부, 외부 발송 전 '확인 후 발송' 설정, 대신 전화는 사내 규정 확인
